# Singalong 1.2.0-rc.2 — card redesign and folder-scan fix

Version **1.2.0-rc.2 (17)** is a phone-test candidate on the lyric-card branch. It has not been merged, tagged or published. Main remains prepared 1.1.0 source; the latest public APK remains v1.0.0.

- Pinned rounded-square preview and compact Looks, Text, Details and Lines sections; a side-by-side layout on short landscape windows.
- Eight compositions: Afterglow, Signal, Margin, Spotlight, Sleeve, Postcard, Duet and Gallery. Presets vary artwork, lyric, song-detail and logo placement.
- Six coordinated palettes, seven named offline fonts, three text sizes, alignment and four output formats. No free-positioning, hex or shade controls.
- Toggle title, artist, album, available filename/file location, cover and app name. The Singalong icon remains; extra branding and source footers are removed from images. Original stored lyrics and attribution stay intact.
- Timestamp-only responses no longer reach the folder save assertion. Plain lyrics are used when available; empty versions are skipped and scanning continues.

See the [checkpoint](docs/validation/card-refresh-checkpoint.md) for automated verification and remaining phone checks. No device/emulator tests are claimed as executed.
