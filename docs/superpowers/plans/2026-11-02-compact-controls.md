# Compact reading and control refinements

> Historical design/plan snapshot. Later accepted scope and current release instructions are in the [documentation index](../../README.md). Preserve this record as dated evidence.

User-authorized follow-up to the phone-feedback revision; keep the accepted visual direction. New feedback images remain local and ignored. Execute inline.

1. Add persisted minimal floating mode: lyric-only surface, tap to reveal actions, drag to move, switch back to compact/expanded. Keep the edge handle and clear accessible exits. Allow 12–32sp originals, 10–22sp translations, 20–96% glass opacity, 160–560dp width, 120–640dp regular height and 56–240dp minimal height. Keep text fully opaque with a shadow at low panel opacity; preserve a readable fallback when blur is unavailable.
2. Make sync controls independent of candidate count. Existing experimental behavior only accepted uncertain timed matches. Add explicitly estimated character-weighted scrolling for untimed lyrics when duration/position are known, opt-in per version with an off switch. Never persist invented timestamps. Add 50ms/250ms/1s adjustment steps, direct offset entry and line alignment, with a floating sync toggle.
3. Add installed app icons loaded locally, styled secondary buttons throughout, and Now footer breathing space.
4. Reduce translation latency with progressive validated partial display, cached segments first, deduplication and at most two concurrent requests. Preserve daily quotas, cancellation, original-first display and complete-version cache validation. Official Google/DeepL need account/key setup; keep the approved keyless scope. Deep-translator is a client library, not a new free hosted API.
5. Add About at the bottom of Settings with build/author/platform/source/privacy details and browser feedback link following `D:/Code/kmab-feedback/docs/INTEGRATION.md`: product=singalong, source=android, version=current build, ctx_screen=about. Do not submit reports, upload feedback media or embed secrets. Check whether the product is registered using public configuration only.
6. Explicitly suppress sound, vibration, lights and badges for tracking, retain valid foreground-service importance, and provide Android channel settings for user-controlled icon visibility. Do not evade Android's mandatory foreground-service disclosure or replace channels to undo user settings.
7. Add behavior regression tests, then run debug/release unit tests, lint, debug/instrumentation/release assembly with existing JDK/SDK. Reuse the release key, verify/sign/archive the local APK and mapping, document phone checks, commit and push.

Acceptance: toggle minimal/control modes without losing geometry; exit minimal using touch and TalkBack; estimated sync works for a single untimed result and turns off; fine offset edits don't alter original lyrics; small settings values survive restart; app icons don't block UI; partial translations appear before completion and cannot bleed into another version; feedback URL contains no lyric or device/user identifiers; background tracking remains compatible with Android notification rules.
