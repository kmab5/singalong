# 1.1 site preparation checkpoint

Date: 2026-11-04. Scope: local static-site changes for the prepared 1.1 release.

## Implemented source

- Added a separate **Preparing 1.1 · not yet released** section using the existing kmab purple, glass surface, typography and spacing. Its four feature groups cover word timing and the off switch, folder scans and sorting, responsive floating controls, and whole-text Google Translate with a clipboard fallback.
- Distinguished supplied word timing from estimated glow. Explained that folder scans send song details, not audio, and that Google Translate is an optional external service.
- Preserved the published v1.0.0 fallback metadata and all three latest-stable APK links. The existing public release API can update these together after a stable release with an APK is actually published. No release was published as part of this site work.
- Extended `tools/check_site.cjs` to check the unreleased label, four feature groups, their layout at all tested widths, and their visibility without JavaScript.

## Verified locally

`node tools/check_site.cjs` passed using the existing installed Playwright module and Chrome, with `PLAYWRIGHT_MODULE` and `CHROME_PATH` set. No browser or SDK packages were installed.

- Tested widths: 320, 390, 768, 1024 and 1440 pixels, served under the `/singalong/` project path.
- No horizontal overflow or clipped preparation text; translated lyric panels stayed within their stage in floating, expanded and minimal modes.
- Display controls, next line, English subtext, docking focus, edge restore, keyboard activation, skip link and reduced-motion behavior passed.
- All four downloadable assets and local anchors resolved. Content and stable download links remained available without JavaScript.
- Mocked release responses verified coordinated APK/version/size/release-link updates, prerelease exclusion, and empty/malformed/network-failure fallbacks. These fixtures are not evidence of a live 1.1 release.
- No browser page errors or failing resource responses occurred in the checked local scenarios.
- Desktop and mobile full-page screenshots in ignored `artifacts/site-desktop.png` and `artifacts/site-mobile.png` were visually reviewed. The new section preserves the existing visual hierarchy and stacks its feature groups on narrow screens.
- `git diff --check` passed.

## Not established by this checkpoint

This does not verify the Android app on a phone, acceptance of text by Google Translate, hosted CI, GitHub Pages deployment of this update, or publication of 1.1. The [November 2 site checkpoint](site-checkpoint.md) remains historical evidence for the earlier deployment.
